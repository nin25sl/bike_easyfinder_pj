# タイトル

> **目的とゴールの違い**
>
> - **目的** = Why（なぜこの設計が必要か／この設計の役割）
> - **ゴール** = Done 条件（どこまで設計すれば完了か／レビュー可能な粒度）

## 目次

<inline-toc preview="3"></inline-toc>

## 目的

- この設計の役割

## 背景

- なぜこの設計が必要か

## ゴール

- どこまで設計するか

## ファイル名

- 対象ファイル or モジュール

## 役割

- このファイルの責務（1行で）

## 本文

### 構造

- クラス/関数構成

### 処理フロー

- 入力 → 処理 → 出力

### インターフェース

- 引数 / 戻り値

### 依存関係

- 外部サービス / 他モジュール

- バグりやすいポイント
