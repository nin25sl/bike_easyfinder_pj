# タイトル

> **目的とゴールの違い**
>
> - **目的** = Why（なぜやるか／何のためか）
> - **ゴール** = Done 条件（何が揃えば完了か／測定可能な完了条件）

## 目次

<inline-toc preview="3"></inline-toc>

## 目的

- 何を解決するのか（1行で書け）

## 背景

- なぜ今やるのか
- 放置すると何が起きるか

## ゴール

- **完了条件**（測定可能に）
- **やらないこと**（スコープ外）

## 本文

### 全体像

- システム構成・流れ

### 方針

- 技術選定理由
- トレードオフ

### リスク

- 想定リスクと対策
