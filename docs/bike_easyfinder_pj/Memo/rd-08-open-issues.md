# RD-08 未解決課題

更新日: 2026-09-27  
状態: RD-08 条件付き承認の残課題

## 1. 一般Web Sourceの信頼性評価

- 課題: ドメイン単位の固定ランクだけでは、記事の更新日、根拠、一次情報への参照、属性ごとの専門性を評価できない。
- 決定済み境界: 収集可否とCanonical採用可否を分離し、利用条件・根拠未確認の値はCanonicalへ自動採用しない。
- 基本設計Todo: 属性別の信頼度算定、ドメイン評価、一次情報参照、複数Source一致の重みと閾値を定義する。

## 2. Source矛盾時の最終採用ルール

- 課題: 公式サイトと一般Web等で営業時間などが異なる場合の属性別決定表が未確定。
- 決定済み境界: 固定の「公式 > OSM > その他」だけで決めず、自動決定不能時は既存Canonical値を上書きせず属性単位レビューへ送る。
- 基本設計Todo: 名称、座標、営業時間、営業状態、駐車場、二輪可否ごとの権威Source、鮮度、確認方法、同値判定を定義する。

## 3. 手動レビュー運用

- 課題: 担当者、SLA、割当方法、期限超過時の警告・非表示判断が未確定。
- 決定済み境界: 安全・営業に関する重大疑義は確認まで非公開、それ以外は属性別Freshness処理に従う。
- 運用設計Todo: レビュー責任者、優先度、期限、エスカレーション、監査記録、滞留指標を定義する。

## 4. 行動イベント

- 依存: RD-05のカード表示、興味あり、興味なし、行ったことがある、興味あり一覧のUX確定。
- 再レビュー項目: `shown / interested / not_interested / visited / selected / route_started` の要否、発火条件、端末状態との対応、取消・再操作、重複計上ルール。
