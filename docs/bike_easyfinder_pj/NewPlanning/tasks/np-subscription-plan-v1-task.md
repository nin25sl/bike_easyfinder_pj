# サブスクリプション企画 v1 作成タスク

## 担当部門

- 新規企画部（NP）

## 目的

承認済みMVP要件を前提に、価値検証を妨げずに継続収益へつなげるサブスクリプションの仕様候補、導入時期、検証方法を定める。価格は仕様と利用実態を確認した後に決定する。

## 影響と変更概要

- `NewPlanning/subscription-plan-v1.md` を新規作成する。
- 現行MVPの対象外である課金機能を即時実装せず、限定β後の要件変更候補として整理する。
- 無料版と有料版の責任境界、料金、無料体験、ペイウォール導線、収益性の目安を定義する。
- 提案件数と興味あり保存件数を価格差の候補として調査し、固定前の検証項目として定義する。
- 件数、比較・計画、個人化、記録、共有など、複数の課金仕様パターンを比較する。
- すべての仕様案を、登録促進に使える新規施策バックログとして保持する。
- 競合料金は2026-09-27時点の公式情報を使用する。

- [x] 全仕様案を削除せず、新規施策として段階実行できる管理方針を定義する。

## 完了条件

- 初期プランに採用できる仕様候補と優先順位が明確である。
- 無料版に残す価値と、有料化する価値が説明できる。
- 提案件数と興味あり保存件数について、初期仮説、計測項目、確定基準がある。
- 価格は仕様検証後に決定する事項として分離されている。
- すべての仕様案が登録促進施策として追跡可能である。
- MVP要件への影響と導入前の承認事項が明確である。
- 実験KPIと継続・変更・中止の判断基準がある。
