# Bike EasyFinder Privacy Policy 草案 v1

> 公開前に運営者名、住所、連絡先、施行日、採用Provider、データ保存リージョン、委託先を確定し、専門家レビューを行うこと。

## 1. 取得する情報

- 推薦処理中の正確な現在地
- 利用者が端末へ保存する前回条件、興味あり、興味なし、行ったことがある情報
- 利用者が分析へ明示同意した場合だけ、ランダムなanalytics installation ID、同意記録、表示・リアクション・目的地選択・外部Map起動イベント
- 障害解析と不正対策に必要な最小限の運用ログ

氏名、メールアドレス、電話番号、広告ID、生GPS軌跡、バックグラウンド位置、連絡先、写真、健康情報はMVPで取得しない。

## 2. 利用目的

- 利用可能時間と興味に合うツーリング先の推薦
- 推薦品質、画面操作性、サービス継続判断のための統計分析
- 障害解析、不正利用防止、安全な運用

広告、データ販売、クロスアプリ／クロスサイトトラッキング、フィンガープリンティングには利用しない。

## 3. 分析への同意

分析は初期状態で無効であり、明示的に同意した場合だけ開始する。同意しなくても推薦機能を利用できる。設定画面からいつでも撤回でき、撤回時は新規収集を停止し、既送信の生データの削除を開始する。

## 4. 保存期間

- 正確な現在地: 推薦リクエスト終了まで。サーバでは最大5分
- 生の分析イベント、analytics installation ID: 最終イベントから90日以内
- 同意記録: 同意中および撤回後90日
- 運用・セキュリティログ: 30日
- 個人または端末へ戻せない日次集計: 13か月
- 削除要求の最小監査記録: 完了後1年

## 5. 外部サービスへの送信

推薦用の現在地と目的地を所要時間計算Providerへ、Spot座標を天気Providerへ、利用者が選択した目的地を外部Mapへ送る場合がある。具体的な送信先、目的、保存リージョンはProvider選定後かつ公開前に本ポリシーへ記載する。analytics installation IDやリアクションをこれらのProviderへ結合して送らない。

## 6. 削除

設定画面から分析データの削除を要求できる。稼働中のシステムから7日以内に削除し、バックアップ内の対象データは復元時に再有効化せず、35日以内に世代期限で消去する。個人または端末へ戻せない5件以上の日次集計と、削除完了を証明する最小監査記録は削除対象外とする。

削除用情報を失った場合、匿名設計のため本人照合による復旧はできない。旧データは最終イベントから90日で自動削除され、再インストール後の新しいIDとは紐付けない。

## 7. 安全管理

通信の暗号化、環境ごとの秘密情報分離、最小権限、保持期限による自動削除、バックアップ復元時の削除台帳適用、アクセスおよび削除処理の監視を行う。
