# iOS固定データ版 UI実装 v1 タスク

## 目的

承認済み基本設計書と、ユーザーから実装着手を指示されたUIデザイン案を、固定Spotデータで操作確認できるiOS 17以上のSwiftUIアプリへ反映する。

## 変更概要と影響

- 既存の検索条件・候補一覧を、S01〜S08の画面フローと単一カード型の逐次提案へ置き換える。
- 前回条件、オンボーディング状態、リアクション、興味ありSpotを端末内へ保存する。
- 条件選択、位置権限、候補0件、推薦失敗、Undo、Apple Maps起動失敗を別状態として扱う。
- API、WeatherKit、分析イベント送信は今回の固定データ版には含めず、差し替え可能な境界を維持する。
- 既存の推薦モックとテスト変更を尊重し、同じファイルの既存差分を失わない。

## 実装結果

- S01〜S08をNavigationStackで接続し、初回と再訪の開始点を分離した。
- 位置情報は提案操作ごとに取得し、推薦処理後にメモリから破棄する。
- 15分の安全余裕を推薦フィルタと表示時間へ追加した。
- リアクションとSpotスナップショットはSwiftData、前回条件等はUserDefaultsへ保存する。
- Windows環境にはXcode、Swift、XcodeGenがないため、iOSビルドとXCTest実行は未実施。macOSでREADME記載コマンドを実行する。

## 完了条件

- 初回と再訪の両方で設計どおりの主要導線をたどれる。
- 推薦候補は一覧ではなく1件ずつ表示され、最大5件で終了する。
- 興味あり保存、直前リアクションのUndo、履歴消去が端末内で機能する。
- 位置情報は提案開始時だけ取得し、保存しない。
- Swiftのビルドまたは、実行環境上可能な静的検証と既存自動テストを実施する。
