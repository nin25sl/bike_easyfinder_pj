# 指定時間推薦・地図改善 v1 実装タスク

## 担当部門

- システム開発部（SC）

## 影響と変更概要

- 推薦候補を近距離順の先頭10件に限定せず、希望所要時間に近い地点を事前選別する。
- 希望所要時間の許容差を原則±15分とし、0件の場合だけ±60分まで15分刻みで拡張する。
- 提案画面に目的地地図、詳細画面に再取得した現在地と目的地を表示する。
- 現在地はメモリだけに保持し、詳細画面終了時に破棄する。
- 画像収集は本タスクでは実装せず、ライセンス・帰属・保存方式を含む後続設計として整理する。

## タスク

- [x] 現行推薦、MapKit、CoreLocation、画像データフローの影響を調査する。
- [x] 基本設計書とテスト計画書へ変更方針を反映する。
- [ ] 推薦ロジックとAPI警告を実装する。
- [ ] iOSの警告表示、提案地図、詳細地図、現在地再取得を実装する。
- [ ] BackendとiOSの自動テストを追加・実行する。

## 完了条件

- 4時間指定時は原則3時間45分〜4時間15分の候補だけを返す。
- 原則範囲が0件の場合だけ許容差を段階拡張し、利用者へ明示する。
- 提案画面で目的地、詳細画面で現在地と目的地を確認できる。
- 位置権限拒否・取得失敗でも目的地地図と既存機能を利用できる。
- 自動テストが成功し、実機未検証事項が明示されている。
