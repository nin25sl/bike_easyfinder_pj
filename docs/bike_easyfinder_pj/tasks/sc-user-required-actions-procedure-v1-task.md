# MVPユーザー実施事項手順書 v1 作成タスク

## 目的

現行実装と既存資料を基準に、AIだけでは完了できず、ユーザー本人のアカウント操作、実機操作、判断または承認が必要な事項を一つの手順書へ集約する。

## 影響と変更概要

- 対象はドキュメントのみとし、アプリ、API、Worker、DBの実装は変更しない。
- 既存の手順書、設計書、引継ぎ資料を正本として参照し、内容を重複実装しない。
- 秘密情報を文書、Git、ログへ記録しない。
- 未完了事項を優先度、完了条件、証跡、参照先とともに明示する。

## タスク

- [x] `.cursor/rules` と保存先を確認する。
- [x] 現行実装と既存資料からユーザー実施事項を抽出する。
- [x] `Procedure` に結論先行のチェックリストを作成する。
- [x] frontmatter、内部リンク、秘密情報の扱い、Procedure API同期可否を検証する。

## 完了条件

- ユーザーが最初に着手すべき事項と、その後の順序が冒頭だけで判断できる。
- 各事項に「誰が何をするか」「完了条件」「残す証跡」がある。
- AI実装済み事項と、ユーザー作業待ち事項が明確に分離されている。
- 九州7県全域・既存MVPデザイン案という確定済み方針を再質問しない。

- `Procedure/mvp-user-required-actions-v1.md`を作成した。
- 必須frontmatterと相対リンクを検証し、参照先がすべて存在することを確認した。
- `PUBLIC_API_BASE_URL`と`PROCEDURE_TOKEN`が環境変数および`.env`に設定されていないため、Procedure APIへの同期は未実施である。秘密値を文書へ記載せず、設定後に投稿する。
